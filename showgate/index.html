ShowGate

The room obeys the human. Claude runs the show inside the rules.

ShowGate is the connector between Claude and a Q-SYS Core. It speaks QRC, Q-SYS’s own external control protocol (JSON-RPC over TCP, port 1710), and gives Claude a short list of tools with the crew’s rules built in. Concept by Ovi, built with Claude.

The rules, in the code

  • The human holds the switch. OFF: Claude gets no access at all, not even to look. WATCH: Claude can read the room, never change it. ON: Claude can act. No switch file means OFF.

  • Allowlist. Claude can reach five channels and four scenes. Nothing else exists for it.

  • HUSH is locked twice. ShowGate has no HUSH tool, and the Core refuses outside access to the HUSH logic, so even a direct login can’t reach it.

  • Nothing counts without a read-back. Every move is sent, then read back from the Core and reported as verified or not. Claude is never its own witness.

  • Everything is recorded twice. The Core keeps its own audit log under Claude’s user name, and ShowGate logs every call.

What is still simulated

The Core in this test is a stand-in that imitates QRC. These still have to be confirmed on a real Q-SYS Core:

  • the exact error codes
  • that a component with outside access turned off is refused over QRC
  • how Q-SYS user permissions limit an outside login

Q-SYS Designer’s Emulate mode has no audio, so the first real test proves control and read-back, not sound.
